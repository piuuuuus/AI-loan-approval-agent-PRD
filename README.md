## 简介

一份面向个人消费贷场景的 AI 产品立项 PRD，核心设计：**AI 辅助 + 人工复核**——LLM 不做最终放款决策，负责材料智能审核与审批意见书生成，决策权保留在规则引擎 + 评分卡 + 人工审批员，满足国内金融监管对可解释性与人工干预的要求。
